# FlixZone-Movie-Recommendation-App
FlixZone 🎬
Discover the best movies, trailers, and recommendations — all in one place.
📽️ Overview
FlixZone is a modern and responsive movie catalog app built with React and Material UI. Users can explore trending and new releases, watch trailers, and manage a personalized gallery with stunning visuals. Designed for speed, usability, and a seamless movie discovery experience, FlixZone makes movie collections interactive and fun.
🚀 Features
Animated Welcome Screen: Eye-catching transitions and poster animations.
Local Image Gallery: Instantly loads and displays high-quality thumbnail images.
Dynamic Search: Instantly filter movies and genres.
Trailer Modal: Watch embedded YouTube trailers in-app.
Responsive Design: Optimized for laptop and desktop screens.
Easy Customization: Update movies by simply dropping images in the /public/assets/movies/ folder.
🛠️ Technologies Used
React (Frontend UI)
Material UI (MUI) for stylish components and responsiveness
JavaScript (ES6+)
Webpack & Babel (Development setup)
VS Code (Recommended editor)
📥 Installation
bash
git clone https://github.com/yourusername/flixzone.git
cd flixzone
npm install
npm start

Open http://localhost:3000 in your browser.

🔧 Customization
Add new movie images: Place your .jpg files in /public/assets/movies/
Edit movie info: Update the array in src/components/movies.js
Change background or styles: Tweak values in WelcomeScreen.js and NavBar.js
